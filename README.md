# COM-Dino-Hunter

Demo Android build for `Call Of Mini Dino Hunter`.

## Download

Go to the project's GitHub `Releases` page and download the latest `.apk` file from `Assets`.

## Install APK on Android

1. Download the `.apk` file to your Android phone.
2. Open the downloaded file.
3. If Android blocks the install, allow `Install unknown apps` for the browser or file manager you used.
4. Open the `.apk` file again and tap `Install`.
5. Launch the game after installation finishes.

## Notes

- This is a demo build.
- The gem shop uses free claim packs for testing/demo purposes.
- If install fails, remove the older version first and try again.
